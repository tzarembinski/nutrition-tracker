# Quick Start Guide

## Running the Application

### Development Mode

```bash
npm install
npm run dev
```

The application will be available at [http://localhost:3000](http://localhost:3000)

### Production Build

```bash
npm run build
npm start
```

## First Steps

1. **Open the application** in your web browser
2. **Add your first meal** using the meal entry form
3. **View your data** in the Meal History tab
4. **Explore analytics** to see trends over time

## Quick Feature Overview

### Add a Meal
- Select today's date (or any past date)
- Choose meal type (Breakfast, Lunch, Dinner, Snack)
- Enter all nutrition values
- Optionally add notes about the meal
- Click "Add Meal"

### View Your Progress
- Check the summary cards at the top for totals
- Navigate to "Meal History" to see all entries
- Use filters to narrow down your view
- Export data to CSV for external analysis

### Analyze Trends
- Go to "Analytics" tab
- View line charts showing daily nutrition patterns
- Check the daily breakdown table
- Track your progress over weeks and months

## Tips for Best Results

1. **Be Consistent**: Log meals regularly for accurate trends
2. **Use Notes**: Record meal details for future reference
3. **Review Weekly**: Check your analytics weekly to spot patterns
4. **Export Regularly**: Back up your data by exporting to CSV
5. **Set Goals**: Use the averages to set realistic nutrition targets

## Data Management

- All data is stored locally in your browser
- Data persists across sessions
- Export to CSV to back up or transfer data
- Clear browser data will reset the app

## Troubleshooting

**Data not saving?**
- Check if localStorage is enabled in your browser
- Ensure you're not in private/incognito mode

**Charts not displaying?**
- Add at least 2-3 meal entries first
- Check that dates are in the correct format

**Can't enter future dates?**
- This is intentional - only past and current dates are allowed
